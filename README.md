### About This Portfolio

My GitHub portfolio is a work in progress. Much of my professional research involves confidential, proprietary, or client-owned data and code that cannot be shared publicly. As a result, I am gradually adapting selected projects for public demonstration using synthetic or publicly available datasets.

These projects showcase my statistical methods, programming skills, and research workflows, but represent only a portion of my broader research experience. Where synthetic data are used, the results are illustrative and should not be interpreted as empirical findings from the original research.
